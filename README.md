## 🚀 Quick Start Guide

### 1. View the Interactive Executive Dashboard
Simply double-click:
```
MoveInSync_Rating_Intelligence_Dashboard.html
```
This is a self-contained, high-performance HTML/CSS/JS dashboard that works completely offline. It features:
* Real-time KPI summary cards
* Interactive root cause and rating distribution charts
* Detailed Jira-ready Engineering Action Plan (P0 Quick Wins, P1 Core Fixes, P2 Systems)
* "Voice of the Employee" Review Explorer with instant filter buttons (1★, 2★, OTP, Tracking, Routing, Crashes) and real-time search

### 2. Run the Play Store Sentinel Tool
To answer the question *"How are our Play Store ratings?"* at any time:
```powershell
powershell -ExecutionPolicy Bypass -File moveinsync_rating_sentinel.ps1
```
The script will query live Google Play reviews for `com.moveinsync.ets`, calculate the current run-rate average rating, negative sentiment share, and flag critical UX friction signals within 10 seconds.

## 📊 Key Findings Snapshot
* **Current Run-Rate Rating:** **3.77 / 5.0** (with a 30% negative sentiment rate in recent batches, down from historical 4.5+ baseline).
* **Primary Driver of Low Ratings:** 50.5% of negative reviews are **operational commute complaints** (vendor delays, route detours, unassigned cabs) that commuters vent on the Play Store due to a lack of rapid in-app escalation channels.
* **Top Product Friction Points:**
  1. **Forced Post-Ride Rating Modal** (locks users in the app without a skip button).
  2. **Intrusive "Seatbelt Safety First" modal** intercepting OTP clicks while boarding.
  3. **Map Auto-Zoom Reset** overriding manual zoom every 3-4 seconds.
  4. **Post-update Room DB migration crashes** in recent releases (v12.18–v12.20).
* **Developer Response Rate on Negative Reviews:** **0.0%** (0 out of 212 negative reviews received a reply).
